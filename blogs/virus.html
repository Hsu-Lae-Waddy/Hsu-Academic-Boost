🗓 15 July 2026 👤 Teacher Hsu Lae Waddy

အန္တရာယ်အများဆုံး Virus က... လူရဲ့ အမှား (Human Mistakes) ပါ။

လူတော်တော်များများက Computer Virus ဆိုရင် 🦠 Malware, Trojan, Ransomware တွေကိုပဲ စဉ်းစားကြပါတယ်။

ဒါပေမယ့် Cybersecurity Experts တွေ ပြောတဲ့အရအတိုင်းဆို...

အကြီးမားဆုံး Security Risk က နည်းပညာ မဟုတ်ဘဲ "လူ" ပါ။

ဒီအမှားလေးတွေကပဲ Hacker တွေအတွက် အခွင့်အရေး ဖြစ်သွားနိုင်ပါတယ်။

  • ❌ Password ကို "123456" လိုမျိုး လွယ်လွယ်ထားခြင်း
  • ❌ Email ထဲက မသိတဲ့ Link ကို နှိပ်လိုက်ခြင်း (Phishing)
  • ❌ Software Update ကို မလုပ်ဘဲ ထားခြင်း
  • ❌ Password တစ်ခုတည်းကို Website အများကြီးမှာ ပြန်သုံးခြင်း
  • ❌ Unknown USB ကို Computer ထဲ ထိုးအသုံးပြုခြင်း

    • 💡🔐 Tips for Cybersecurity......

    • Computer ကို ကာကွယ်ဖို့ Antivirus တစ်ခုတည်း မလုံလောက်ပါဘူး။

      • အကောင်းဆုံး Security က User ရဲ့ Awareness နဲ့ အလေ့အကျင့်ကောင်းတွေပါ။

    • ✅ Strong Password သုံးပါ။
    • ✅ Two-Factor Authentication (2FA) ဖွင့်ထားပါ။
    • ✅ Software တွေကို အမြဲ Update လုပ်ပါ။
    • ✅ မသေချာတဲ့ Link နဲ့ Attachment တွေကို မဖွင့်ပါနဲ့။

    လို့ စိုးရိမ်နေတဲ့သူတွေ ရှိနေဆဲပါ။

    📚 Summary...

    🔐 Cybersecurity ဆိုတာ Technology တင်မဟုတ်ဘူး—လူရဲ့ ဆုံးဖြတ်ချက်တွေလည်း အရေးကြီးပါတယ်။
