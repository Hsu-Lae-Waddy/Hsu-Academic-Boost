🟡 HTML Only Website

In this lesson, you will build your very first website using only HTML.

We will not use CSS or JavaScript yet. Our goal is to understand the basic structure of a webpage.

🎯 What You Will Learn

  • Create an HTML file
  • Add headings
  • Add paragraphs
  • Insert images
  • Create links
  • Create lists

📌 Step 1: Create index.html

Create a file named:

index.html

📌 Step 2: Basic HTML Structure

<!DOCTYPE html> <html> <head> <title>My First Website</title> </head> <body> </body> </html>
Tag Purpose
<html> Root element of the webpage.
<head> Contains page information.
<title> Shows the page title in the browser tab.
<body> Contains everything displayed on the webpage.

📌 Step 3: Add a Heading

<h1>Welcome to My Website</h1>

Welcome to My Website

📌 Step 4: Add Paragraphs

<p>Hello! My name is Alex.</p> <p>I am learning HTML.</p>

Hello! My name is Alex.

I am learning HTML.

📌 Step 5: Add an Image

<img src="cat.jpg" width="200">

📌 Step 6: Add a Link

<a href="https://www.google.com"> Visit Google </a>
Visit Google

📌 Step 7: Add a List

  • Reading

  • Coding

Tag Purpose
